# coffee_shope_website
# ☕ Coffee Shop Website

A modern and responsive Coffee Shop Website built using **HTML, CSS, and JavaScript**. This project showcases a stylish coffee shop landing page with sections for Home, About, Menu, Products, Customer Reviews, Contact, and Blog.

## ✨ Features

* Responsive Navigation Bar
* Attractive Home Section
* About Us Section
* Coffee Menu Display
* Featured Coffee Products
* Customer Reviews
* Contact Information
* Blog Section
* Mobile-Friendly Design
* Smooth User Experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
* Google Fonts

## 📂 Project Structure

```bash
Coffee-Shop/
│

```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
